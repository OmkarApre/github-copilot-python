# Sudoku Game (Flask + Copilot Refactor)

- A Sudoku game built with Python Flask, refactored and extended using GitHub Copilot with async routes, difficulty levels, hints, a timer, and a Top 10 leaderboard.

## Setup
- bash
- cd starter
- python -m venv .venv
- .venv\Scripts\Activate.ps1
- pip install -r requirements.txt
- python app.py

[Open http://127.0.0.1:5000 in your browser.]

## Running Tests
- bash
- python -m pytest tests
